# Tree Delivery — Busca em Árvore Binária de Busca (ABB)

Projeto acadêmico de Estruturas de Dados II.

## Objetivo
O jogador precisa localizar o código de uma entrega utilizando as regras de uma Árvore Binária de Busca (ABB).

A árvore utilizada é formada pelos valores:
`50, 30, 70, 20, 40, 60, 80`.

- valor menor que o nó atual: esquerda;
- valor maior: direita;
- valor igual: entrega encontrada.

Exemplo para localizar a entrega 60: `50 → 70 → 60`.

## Como executar
Baixe os arquivos e abra `index.html` em qualquer navegador. Não é necessário instalar bibliotecas.

## Funcionamento
O jogo sorteia um código de entrega. O jogador escolhe Esquerda, Direita ou "É esta!". O sistema fornece feedback, contabiliza passos e erros e mostra o caminho percorrido.
